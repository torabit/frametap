# hid_probe 実行手順

Windows 実機で DualSense の HID を読み取れるか確かめるための調査用ツール。Steam と Dark Souls Remastered を起動したまま動かし、出力ログをそのまま返してほしい。

所要目安は約 30 秒。

## このツールが何をするか

Sony の HID デバイスを一覧し、DualSense を 1 つ読み取り専用で開く。入力レポートを 300 件受け取り、受信間隔の統計を出して終了する。

コントローラへの書き込みは行わない。`write` と `send_feature_report` は呼んでいない。

## 用意するもの

- Windows 10 または 11 の PC
- DualSense
- Steam
- Dark Souls Remastered

## 手順

### 1. hid_probe.exe を入手する

GitHub Release に添付された `hid_probe.exe` を落とす。置き場所は `C:\Users\<名前>\Downloads` のような普通のフォルダでよい。

### 2. 警告が出たときの対処

**SmartScreen**

「Windows によって PC が保護されました」という画面が出た場合は、「詳細情報」を押すと「実行」ボタンが現れるので、それを押す。

**ウイルス対策ソフト**

Windows Defender やサードパーティ製のソフトが exe を隔離した場合は、実行せずにその時点のスクリーンショットを送ってほしい。除外設定の追加やセキュリティ機能の無効化はしないでほしい。

判断に迷ったときも、実行せずにスクリーンショットを送ってもらえれば十分。

### 3. Steam と Dark Souls Remastered を起動する

1. Steam を起動する
2. Dark Souls Remastered を起動し、タイトル画面まで進める

この状態を保ったまま次へ進む。ゲームは終了しない。

### 4. DualSense を接続し、接続方式を記録する

DualSense を PC につなぎ、どちらでつないだかを控える。

- USB ケーブル
- Bluetooth

### 5. hid_probe.exe を実行してログを取る

`hid_probe.exe` を置いたフォルダを開き、アドレスバーに `powershell` と打って Enter を押す。そのフォルダで PowerShell が開く。

PowerShell の場合:

```powershell
.\hid_probe.exe > log.txt 2>&1
```

コマンドプロンプト (cmd) を使う場合:

```
hid_probe.exe > log.txt 2>&1
```

`2>&1` はエラー出力もファイルに入れるための指定。これが無いとエラーがログに残らないので、必ず付けてほしい。

実行中はコントローラのスティックを適当に動かし続ける。終了するとプロンプトが戻り、同じフォルダに `log.txt` ができている。

### 6. log.txt の全文を返す

一部を抜き出したり要約したりせず、全文を貼り付けるか、ファイルごと添付してほしい。

## こちらで見ること

ログに出る受信間隔の `median` が 3000 から 5000µs の範囲に入るかどうかを記録する。範囲を外れていてもそのまま返してほしい。値の意味はこちらで判断するので、数字を見て実行し直す必要はない。

## うまくいかないとき

### exe が起動しない、すぐ終わる

`log.txt` の中身をそのまま返してほしい。それが答えになる。

### 「対象デバイスが見つからない」と出る

その `log.txt` をそのまま返してほしい。ログの先頭に Sony のデバイス一覧が出ているので、何が見えているかはこちらで分かる。

### デバイスを開く段階でエラーが出る

回避策を探さないでほしい。管理者権限で実行し直す、Steam を終了する、別のツールで試す、といった対処は不要。Steam 起動中に開けるかどうかがこの調査の目的なので、Steam を止めると測りたいものが測れなくなる。

エラーメッセージの全文を `log.txt` ごと返してもらえれば十分。

### ログが途中で止まっている

300 件に届く前に read が失敗した状態。その `log.txt` をそのまま返してほしい。何件目で止まったかがメッセージに入っている。
